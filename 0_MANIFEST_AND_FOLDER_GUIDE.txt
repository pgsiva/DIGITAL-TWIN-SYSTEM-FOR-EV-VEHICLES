EV DIGITAL TWIN - FLAT FILE MANIFEST
======================================

This zip has NO subfolders - every file is flattened into one folder.
The '__' in each filename marks where a folder separator used to be.
To rebuild the real project structure (needed for the Java backend
and for the frontend's relative links to work), on GitHub.com:

  1. Click 'Add file' -> 'Create new file' in your repo.
  2. In the filename box, type the FULL PATH shown below (e.g.
     'frontend/home-page/index.html') - GitHub creates the folders
     automatically as you type the '/'.
  3. Paste in the contents of the matching flattened file.

Or, if you have any terminal access (even Termux/Codespaces), unzip
this file and run the included rebuild.sh to recreate the folders
automatically in one step.
